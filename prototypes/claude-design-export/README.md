# Claude Design Export

Original static prototype export.

## Entry Points

- `Home.html` - marketing page prototype.
- `Nina's Pet Salon.html` - branded salon dashboard prototype.
- `Glasshound.html` - Glasshound SaaS dashboard prototype.
- `Glasshound v1 (multi-stylist).html` and `Glasshound v2 (dark academia).html` - duplicate/variant entry files from the export.

## Notes

- These files use browser-loaded React, Babel, and hardcoded demo data.
- They are reference-only and are excluded from linting and Docker packaging.
- Production implementation lives in `src/`.
